# Simple Interest Calculator

A simple Bash shell script that calculates simple interest.

## Formula

Simple Interest = P × R × T

Where:
- P = Principal amount
- R = Annual rate of interest
- T = Time period in years

## Usage

Run the `simple-interest.sh` script and provide the principal amount, annual interest rate, and time period.

## Example

For a principal of $1000, an annual interest rate of 5%, and a time period of 2 years:

Simple Interest = 1000 × 0.05 × 2 = $100
